# 候选源码的安全复查边界

原私有项目的原始发现记录、Git 身份和历史扫描输出不随此快照分发。本文件是通用边界说明，不是原审计报告，也不宣称完成渗透测试或任意编码秘密的完备检查。

候选保留输入边界、用户授权、事务约束、有限重试、未知 Commit 结果核验和日志脱敏测试。固定测试输入、脱敏哨兵及一次性 CI/性能凭据应与真实秘密区分；第三方许可证的上游姓名/邮箱是合法归属。

不纳入 .git、真实 .env、Session manifest、逐条认证记录、dump、备份、原始日志、缓存、工具二进制或原始安全发现。当前只有源码、配置示例、必要文档及经文件级复查的合成聚合实验数据。

独立展示 Git 仓库的历史、noreply 身份与已核实云端运行分别记录于 [ci.md](ci.md)。每次变更仍需重新审查内容、来源、准确提交与实际日志；动态 Badge 和历史 Run 不能替代隐私、素材权利或部署安全检查。问题报告及部署边界见 [SECURITY.md](../SECURITY.md)。
